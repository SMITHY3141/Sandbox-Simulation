# Simulation-Sandbox

A general simulation tool for visualising (in real time) and controlling numerical simulations. 

In it's current form, it's mainly used as a testbed for missile control simulations (testing acceleration, attitude, and pitch rate autopilots for a 2D non-linear missile model).

It's capable of graphing simulations up to a fixed time or rendering a simulation in real-time.
Simulations can be saved, edited, and loaded without needing to alter any code.
